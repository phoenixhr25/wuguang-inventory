# 隐私与数据说明

更新日期：2026-09-28

## 当前版本保存什么

用户可以输入物品名称、分类、数量、购买金额、颜色和收纳位置，并选择照片。使用“今天用过”或“今天穿了这套”会生成使用记录。

## 数据保存在哪里

当前版本把物品、照片和使用记录保存在当前浏览器的 IndexedDB 中。Streamlit Python 服务只提供页面，不接收用户选择的照片，也没有云端用户数据库。

不同设备、不同浏览器、微信内置浏览器和系统浏览器可能使用彼此独立的数据空间。

## 数据可能如何丢失

- 清理浏览器或微信缓存；
- 使用无痕模式；
- 更换手机或浏览器；
- 浏览器回收网站存储空间；
- 网站域名发生变化。

录入一批物品后，请使用“数据与备份”导出完整备份。

## 备份包含什么

JSON 备份包含物品字段、照片和使用记录。它可能暴露用户拥有的物品、购买金额和收纳位置，应像私人文件一样保管。

不要把真实备份上传到公开 GitHub Issue、论坛或聊天群。导入备份会替换当前物品库，导入前建议先导出当前数据。

## 删除数据

用户可以删除单件物品，或在“数据与备份”中清空当前浏览器的全部记录。清空前建议先导出备份。

## 未来 AI 版本

当前版本不调用 AI。未来如启用图片识别，产品会在上传前说明照片发送到哪里、用于什么、保存多久以及如何删除，并提供人工确认。API 密钥只会保存在服务端。
