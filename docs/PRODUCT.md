# 产品说明

## 问题

用户往往看不清自己已经拥有什么：重复购买、忘记已有物品、长期闲置，也难以理解物品总价值和使用效率。

传统库存工具像 ERP，字段多、维护累。物光的产品假设是：如果入口从照片开始，并让系统逐渐承担识别和整理工作，个人物品库才可能被持续维护。

## 核心闭环

```text
照片或手动添加
→ 确认名称、分类、数量和金额
→ 形成个人物品库
→ 查询、发现相似和记录使用
→ 得到搭配或处置建议
→ 实际使用并反馈
```

## 当前版本的定位

当前版本是用于验证闭环的本地 MVP，不是完整商业产品，也没有接入 AI。它重点验证：

- 用户是否愿意从一件物品开始；
- 哪些字段最影响录入；
- 用户是否会再次查看库存；
- 基础穿搭与使用记录是否能提高已有物品利用率；
- 完整备份是否足以支撑早期试用。

## 产品原则

- AI 负责降低录入成本，用户保留最终确认权；
- 不把估算金额冒充真实购买价格；
- 不把“没有记录”直接判断为“闲置”；
- 推荐只能使用真实库存中的物品；
- 数据必须可导出、可恢复、可删除；
- 先验证行为和价值，再建设复杂账户与商业系统。

## 首轮指标

- 至少录入 1、3、10 件物品的人数；
- 从照片到确认一件物品所需时间；
- 每件物品需要填写或修改的字段数；
- 七日内再次打开比例；
- 查看搭配和记录实际穿着的人数；
- 导出备份的人数；
- 用户最希望自动化的步骤。
