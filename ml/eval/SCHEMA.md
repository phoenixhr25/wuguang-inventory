# 标注字段说明

每一行代表照片中的一件目标物品。

| 字段 | 必填 | 含义 |
|---|---|---|
| `image_id` | 是 | 图片文件名，如 `001.jpg` |
| `item_index` | 是 | 同一图片内从 1 开始的物品编号 |
| `name` | 是 | 可由人复核的简短名称 |
| `major` | 是 | `衣物`、`物品`、`数码` |
| `category` | 是 | 对应大类下的二级分类 |
| `quantity` | 是 | 正整数 |
| `color` | 是 | 主要颜色，无法判断时填 `未知` |
| `difficulty` | 是 | `single-clear`、`multi-item`、`occluded`、`low-light` |
| `notes` | 否 | 只记录标注歧义，不写私人信息 |

## 二级分类

### 衣物

`上装`、`下装`、`连衣裙`、`外套`、`鞋履`、`包袋`、`配饰`、`其他衣物`

### 物品

`个人护理`、`运动户外`、`书籍文具`、`兴趣收藏`、`工具器材`、`生活用品`、`其他`

### 数码

`手机`、`电脑`、`平板`、`摄影摄像`、`影音设备`、`智能设备`、`游戏设备`、`数码配件`、`其他数码`

## 暂不标注

第一轮不标注价格、品牌、材质、购买日期、故事、设备状态和具体位置。这些字段缺少照片证据，混入评测会把“模型推测”误当成“识别事实”。
